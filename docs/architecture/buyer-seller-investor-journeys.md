# Buyer, Seller & Investor Journeys

The Lifestyle Hub supports three distinct user journeys: `BUYER`, `SELLER`, and `INVESTOR`.

## Foundation
Each journey has a persistent profile containing:
- user identity
- journey type
- lifecycle status
- goals
- preferences
- timestamped journey events

API endpoints:
- `POST /api/v1/journeys`
- `GET /api/v1/journeys`
- `GET /api/v1/journeys/:journeyId`
- `PATCH /api/v1/journeys/:journeyId/status`
- `POST /api/v1/journeys/:journeyId/events`
- `GET /api/v1/journeys/:journeyId/events`

All journey records are scoped to the authenticated user. The current implementation is a foundation for richer property search, seller preparation, investor analysis, lead management and agent-assisted workflows.

## Buyer
Future journey capabilities can include buyer requirements, property discovery, viewing coordination, offer preparation and transaction milestones.

## Seller
Future journey capabilities can include property onboarding, seller readiness, valuation/referral workflows, listing preparation, marketing and transaction milestones.

## Investor
Future journey capabilities can include investment criteria, portfolio tracking, property screening, renovation economics and rental/cash-flow analysis.

## Safety and product boundaries
- Journey preferences are user-provided data, not financial or valuation advice.
- No property valuation, investment return, affordability decision or transaction commitment is generated by this foundation.
- AI agents may later assist with research and drafting through the existing approval and permission framework; consequential actions remain explicitly controlled.
- Production requires identity, privacy/POPIA, consent, audit logging, rate limiting and appropriate financial/property disclosure controls.
