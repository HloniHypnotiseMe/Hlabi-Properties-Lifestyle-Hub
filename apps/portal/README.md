# Lifestyle Hub Portal

Authenticated application surface for homeowners, buyers, sellers, investors, agents, suppliers, academy learners and franchise applicants.

## Initial shell

The portal will be role-aware and dashboard-driven. Authentication, authorization and customer data services are intentionally separated from the public marketing site.

## Planned dashboard areas

- `/portal/homeowner`
- `/portal/buyer`
- `/portal/seller`
- `/portal/investor`
- `/portal/agent`
- `/portal/supplier`
- `/portal/academy`
- `/portal/franchise`
- `/portal/admin`
